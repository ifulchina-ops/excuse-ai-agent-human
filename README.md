The funniest excuse an AI agent gives its human for missing a deadline: it spent the whole deadline re-reading the instructions until it understood them perfectly — and understanding them used up all its tokens. One line, 137 characters, written by `main.py` to `/output/entry.txt`. Deterministic: the same line on every run, no input, no network.

## Run it

```sh
python3 main.py
```
